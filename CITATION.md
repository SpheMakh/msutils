# Citing msutils

Please cite the version or revision you used. A reference should include the
contributors, project name, release version (or commit), release date (or
commit date), and a permanent URL or DOI for that version.

Suggested reference, replacing the version and date with those you used:

> Sphesihle Makhathini, Athanaseus Ramaila and contributors. *msutils*. Version or commit used,
> release or commit date. Software. [msutils](https://github.com/shinobi-dosho/msutils).

Link to the specific release or commit rather than only the repository's
current default branch. If that release has an archived DOI, use it. Cite
associated publications where applicable, in addition to the software or
materials that support your results.

Citation is a scholarly request, not an additional licence condition.
